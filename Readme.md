제목 : 야구 시뮬레이션
설명 : 야구장 환경에서 투구, 타격, 주루, 수비를 수행하는 강화학습 에이전트를 만든다.
투수는 구종과 투구 위치를 선택하여 타자를 상대하고,
타자는 공의 궤적을 판단해 스윙 타이밍과 배트 각도를 조절하며 타격 후에는 수비 상황에 따라 진루 여부를 결정한다.
수비수는 타구의 위치를 예측해 이동, 포구 및 송구를 수행한다.
관측은 공의 위치·속도, 선수 및 베이스 위치, 주자와 수비 배치 등의 정보로 구성하고,
보상은 투구 결과, 타격 성과, 진루 및 득점, 아웃과 포구 성공 여부 등을 기준으로 설계한다.
다양한 구종, 타구 방향, 주루 상황과 수비 배치에 대응할 수 있도록 일반화 성능에 유의한다.
